# CV web — Rafael Valdez

Sitio estático en HTML, CSS y JavaScript. No requiere compilación ni instalación.

## Publicar en GitHub Pages

1. Sube `index.html`, `styles.css`, `script.js`, `.nojekyll` y toda la carpeta `assets` a la raíz de tu repositorio.
2. En GitHub abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, rama `main`, carpeta **/(root)** y guarda.
4. GitHub mostrará la dirección cuando termine el despliegue.

Los enlaces relativos funcionan también bajo `usuario.github.io/repositorio/`. Debes subir todos los archivos, no solamente el HTML.

## Editar

- Contenido: `index.html`.
- Tecnologías y detalles de soluciones: `script.js`.
- Diseño y versión móvil: `styles.css`.
- CV descargable: `assets/cv-rafael-valdez.pdf`.
- Logo: `assets/logo.svg`.
- Arte generado de portada y contacto: `assets/rv-mountains.png`.

Los datos profesionales se extrajeron del PDF proporcionado. Se priorizaron sus fechas y universidades sobre las referencias gráficas. Las interfaces de proyectos son vistas ilustrativas hechas en HTML/CSS, no capturas de sistemas reales. Los botones muestran experiencia respaldada por el CV. No se inventaron enlaces de GitHub o LinkedIn.

El contacto abre la aplicación de correo o teléfono. Montserrat está incluida localmente en `assets`; no necesita conexión con Google Fonts.

El arte `assets/rv-mountains.png` se generó con la herramienta integrada de imágenes. El prompt completo está en `assets/image-prompt.txt`.
